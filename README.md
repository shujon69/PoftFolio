## ✨ Features

### 🎭 Visual Effects
- **iOS 27 Liquid Glass** — frosted translucent panels with specular light sweep & iridescent refraction edges
- **Floating Gradient Orbs** — animated colorful background blobs (terra, teal, violet, gold)
- **Particle Canvas** — interactive colored particles with connecting lines
- **Liquid Blob Droplets** — morphing glass shapes in hero section
- **Rainbow Gradient Animations** — animated gradient text, bars, meters & underlines
- **Aurora Footer Glow** — rotating conic-gradient light in footer

### 🖱️ Interactions
- **Cursor Refraction Glow** — glass panels follow mouse with soft light (slow lerp)
- **Magnetic Buttons** — buttons attract toward cursor (smooth easing)
- **3D Card Tilt** — project cards rotate in 3D on hover (slow lerp)
- **Specular Light Sweep** — slow glass shine sweep on hover
- **Sparkle Burst** — colorful particle fireworks on section reveal
- **Typewriter Effect** — animated role text with rainbow cursor
